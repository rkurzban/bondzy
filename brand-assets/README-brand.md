# Bondzy — Brand Assets

## Logo (transparent background)

Same logo that's on the site, with the navy background square removed (true transparent PNG).
The decorative sparkle that was in the original's bottom-right corner has also been removed.

| File | Use for |
|---|---|
| `bondzy-logo-transparent-2048.png` | Master / print / anything large. Centered on a transparent square canvas. |
| `bondzy-logo-transparent-1024.png` | High-res web / social. |
| `bondzy-logo-transparent-512.png` | General web use. |
| `bondzy-logo-transparent-256.png` | App header / medium. |
| `bondzy-logo-transparent-128.png` | Small UI / list icons. |
| `bondzy-logo-transparent-64.png` | Favicon-size / tiny. |
| `bondzy-logo-transparent-32.png` | Favicon. |
| `bondzy-logo-transparent-cropped.png` | Tightly trimmed to the figure (no padding) — for when you need to control the margins yourself. |

All the square versions share the same padding, so they line up if you swap sizes.

## Fonts (free, Google Fonts)

- **DM Serif Display** — the "Bondzy" wordmark and all big headings.
  https://fonts.google.com/specimen/DM+Serif+Display
- **Plus Jakarta Sans** — all body text.
  https://fonts.google.com/specimen/Plus+Jakarta+Sans

(Marketing emails use plain Arial on purpose, because email clients can't reliably load custom fonts.)

## Brand colors

| Name | Hex | Where |
|---|---|---|
| Navy | `#1B2A4A` | Primary brand color — headers, hero backgrounds, the "Bondzy" wordmark on light. |
| Gold | `#D4A843` | Accent — the logo figure, buttons, highlights. |
| Green | `#2E8B57` | Success / claimed states. |
| Off-white | `#F5F6F8` | Page background. |

The square the logo was sitting on was a navy *slightly* different from `#1B2A4A`, which is why it showed against the real navy. With the transparent file that mismatch is gone.
